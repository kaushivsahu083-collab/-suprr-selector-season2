# SupeRR Selector Season 2 — Dashboard Deployment

## Publish the dashboard
1. Extract this ZIP on your computer.
2. Create a **Public** GitHub repository named `suprr-selector-dashboard`.
3. Upload every file in this folder to the repository root (not the ZIP itself).
4. Open https://share.streamlit.io/ and sign in with GitHub.
5. Choose **Create app**. Select your repository, branch `main`, and main file `app.py`.
6. Click **Deploy**. When it finishes, copy the public `https://....streamlit.app` URL.
7. Open the link in an incognito/private browser to check that it is publicly accessible, then paste it into the competition dashboard-link field.

## Files
`app.py`, `requirements.txt`, the two Top 10 files, full eligible-score tables, sensitivity results and audit summary.

## Important
Do not upload only the ZIP file to GitHub; extract it and upload the files inside. Keep all files in the repository root.
